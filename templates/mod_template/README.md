# HexForge tileset mod template

A small Godot project with a complete, working tileset mod. Open this folder in Godot (same version as HexForge),
change the art, export, done.

```
mod_template/
├── my_tileset/                 ← your mod, the folder name must be the .pck name
│   ├── mod_info.tres           ← ModInfoResource (required, the loader looks for it)
│   ├── config.tres             ← MapTilesetConfiguration with every optional field filled
│   ├── tileset.tres            ← TileSet: ground tiles, road and river tiles, custom data
│   └── tiles.png               ← the atlas (64x64 pointy-top hexes)
├── resources/definitions/      ← copies of HexForge's resource scripts, so the .tres files open here.
│                                  NOT exported (the game already has them), dont edit them
└── export_presets.cfg          ← "Mod PCK" preset
```

## What is in the example

- **Ground tiles** (row 0): grassland, ocean, desert, forest, each with custom data `biome`, `is_water` and `blend_color`.
- **Road tiles** (row 1) on terrain set 0 / terrain 0 "Road": left-right, the two diagonals and two dead ends.
  Each tile has peering bits on the sides the road leaves through.
- **River tiles** (row 2) on terrain set 0 / terrain 1 "River": same idea, for rivers drawn through the hex centers.
- **An extra road style** "Cobblestone" in `config.tres → path_styles`.

Everything except `mod_info.tres`, `tileset_name` and `tileset_resource` is optional. See the "Modding" section of the
HexForge README for what each field does and what happens when it is missing.

## Making your own

1. Rename `my_tileset/` to your mod name (lowercase, no spaces) and fix the paths inside the 3 `.tres` files
   (or move them in the Godot FileSystem dock, which updates references for you).
2. Replace `tiles.png` and edit `tileset.tres` in the TileSet editor: tile shape, layout and size must match your art.
3. Set `tileset_name` (shown in HexForge's picker) and `tilemap_scale` in `config.tres`.
4. `Project → Export → Mod PCK → Export PCK/ZIP`, save it as `<your mod name>.pck`.
5. Put the `.pck` in HexForge's `tilesets` folder (see the README) and restart HexForge.
6. In HexForge, open the tileset picker and press **Check mod**.

Command line export: `godot --headless --path . --export-pack "Mod PCK" ../my_tileset.pck`

## Regenerating this template

It is generated by `tools/build_mod_template.gd` in the HexForge repository (run it after changing a definition script,
a test checks the copies are up to date).
